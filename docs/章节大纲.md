## 零、角色与伏笔

**奶龙酱**（女主）
- 金发长卷、爱笑、数学不好、怕打雷、会在深夜修兔子玩偶
- 家在外地，寒暑假要回家，父母期望她考研
- 隐藏：她也在偷偷关注男主（音乐节海报右下角的字是她写的）

**男主**（玩家）
- 会弹吉他（宿舍那把），大二，慢热
- 关键道具：吉他、旧书、手机

**六个伏笔**（已在房间可点击，全部要用上）

| 线索 ID | 物件 | 后续作用 |
|---|---|---|
| girl_bunny | 缝过的兔子耳朵 | 第 6 章解开她“为什么总自己修东西” |
| girl_lights | 灯串上的便签 | 第 3 章她怕黑时点出 |
| girl_moon | 月亮的位置 | 第 7 章异地的信物 |
| boy_guitar | 胶带「7.14 礼堂」 | 第 6 章舞台伏笔，也是她认出他的原因 |
| boy_book | 书里的旧照片 | 第 5 章解释他为什么慢热 |
| boy_poster | 海报右下角小字 | 第 8 章结局揭示 |

## 一、总体结构

```
第1章 相遇 → 第2章 靠近 → 第3章 试探 → 第4章 群像
        ↘ 分流点A（第3章末）
                        → 第5章 距离 → 第6章 高光
        ↙ 分流点B（第6章末）
第7章 抉择 → 第8章 毕业季 → 4 个结局
```

- 每章 8–10 场：`对白 ×6 + 选择 ×2 + 探索/小游戏 ×1 + 章末结算 ×1`
- 分流点只有 2 个（A：第 3 章末；B：第 6 章末），其余选择只影响反应与好感，不影响主干

## 二、结局判定

| 结局 | 条件 | 基调 |
|---|---|---|
| 甜 · 一起毕业 | 好感 ≥ 75 且 线索 ≥ 5 且 B 点选“留下” | 在一起 |
| 遗憾 · 各自远行 | 好感 ≥ 60 但 B 点选“让她走” | 体面告别 |
| 成长 · 变成更好的人 | 好感 40–59，无论 B 点 | 开放式 |
| 隐藏 · 海报上的字 | 好感 ≥ 75 且 6 条线索全收集 且 五子棋赢过 | 揭示她早就在看他 |
